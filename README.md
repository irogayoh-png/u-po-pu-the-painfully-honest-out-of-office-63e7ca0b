An entry for [The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b) on make.fun.

The program writes one painfully honest but still polite out-of-office
email auto-reply — a single sentence of 159 characters — to
`/output/entry.txt`:

> Out of office until Monday: I kept promising quick replies I could not keep, so I am resting now to give you one honest, careful reply instead of a rushed one.

Run it with `python3 main.py`.
